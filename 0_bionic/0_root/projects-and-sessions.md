LM Studio Bionic organizes work into **Projects** and **Sessions**.

## Projects

A project keeps related sessions and files together. Choose a project type based on the work:

- A **Work Project** has a Bionic-managed **Workspace** for documents and other non-code work.
- A **Code Project** works with a local folder that you select as its working directory.

Project files give sessions shared working context. A new session has its own conversation, but it can work with files in the same project.

See [Using Work Projects](/docs/bionic/work-projects) and [Using Code Projects](/docs/bionic/code-projects).

## Sessions

A session is a conversation and task thread inside a project. Use separate sessions for work that should have separate instructions or conversation history.

You can **Pin**, **Rename**, **Archive**, or **Delete** a session. Bionic may also label sessions as **Working**, **Unread**, or **Needs Action**.

## Tabs and side-by-side work

Sessions open in tabs. Project files and built-in browser pages can also open as tabs.

To view two sessions side by side, drag a session tab over the left or right half of the current pane. Drop it when the blue target appears. This is useful for comparing results or keeping one task visible while another runs.

You can also use **Fork** on an eligible response to open a new branch beside the current session.

## Workspaces with more than one project

A Workspace window can contain several projects. From **Projects**, use **Open in Workspace** to add a project to the current Workspace, or **Open in New Window** to keep it separate.

Sessions and tabs stay grouped by project.

## Background sessions and notifications

Switching to another tab or project does not stop a running session. Bionic continues the task in the background.

When a background session finishes, Bionic can send a system notification. Select the notification to open the related session. A notification is not sent when a focused Bionic window is already showing that project.
