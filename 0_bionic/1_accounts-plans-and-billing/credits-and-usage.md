Bionic uses credits when a session runs a **Cloud** model. The amount depends on the selected model and the tokens processed.

**Local** models run on your computer. **Remote** models run on a linked device. Neither uses Bionic cloud inference credits.

## View usage

Open **Settings** → **Billing and Usage**.

Choose **Personal** or an available organization under **Billing account**. The page shows usage for the selected account over **Last 30 days**.

You can review:

- **Requests**: the number of cloud inference requests.
- **Spend**: the amount spent on those requests.
- **Input**: tokens sent to the model.
- **Cached input**: input tokens reported as reused from a cache.
- **Output**: tokens generated by the model.

For **Personal** billing, **Remaining credit USD** shows the available balance. Bionic does not show this balance for organization billing accounts.

Select **Refresh** to load the latest account and usage information.

## Keep usage predictable

- Use a **Local** or **Remote** model when cloud inference is not needed.
- Start a new session when old conversation context is no longer useful.
- Attach only the files and images needed for the task.
- Check **Billing and Usage** after a large task.

Bionic shows usage totals, not a fixed cost per task. Model pricing and request size affect the final spend.

To change a plan or add credits, see [Set Up Billing and Add Credits](/docs/bionic/accounts-plans-and-billing).
