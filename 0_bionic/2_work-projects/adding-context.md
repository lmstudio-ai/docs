Add only the context needed for the current task. Tell Bionic what each item is and how it should be used.

## Attach files

Select **Attach files** in the composer, then choose one or more files. You can also paste files or drag them into the composer.

Attached files are included with that message. For a file that should remain available across the project, keep it in **Workspace** or add it as an external Workspace item.

Type `@` in the composer to search **Project files and folders**. You can also drag a file or folder from the Files sidebar into the composer.

## Attach images

Paste or drag an image into the composer, or add it through **Attach files**. Bionic shows an image preview before you send the message.

Choose a model that supports image input. In the prompt, say what to inspect, such as text, layout, a chart, or a visual difference.

## Add folders

Drag a folder into the composer to add a path reference for the current prompt.

To keep an external folder available in a Work Project:

1. Open the **Workspace** options menu.
2. Select **Add folder...**
3. Choose the folder.
4. Review the access prompt and select **Add and allow changes**.

The folder stays in its original location. If you allow changes, LM Studio can create, edit, or delete files inside it. Changes made through Bionic's file tools are saved in project version history.

Use **Add file...** in the same menu to link one external file. Items marked **View only** cannot be changed by Bionic.

## Use browser tabs

Select **Open browser** to open Bionic's built-in browser. Browser pages open as tabs, but a browser tab is not automatically added to the session context.

Provide the URL or paste the relevant content when you want Bionic to use a page.

## Let Bionic search the web

Open **Settings** → **General** and turn on **Web search** to allow Bionic's built-in search and extraction tools. Web search requires sign-in.

Then ask for a web-based task and state any source requirements:

> Find the current documentation for these three tools. Compare their supported export formats and include links to the sources.

Connected websites have their own data practices. See [Privacy in LM Studio Bionic](/docs/bionic/privacy).
