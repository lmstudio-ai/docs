Downloaded models can run on your computer without using cloud inference credits.

## Find a model

1. Open **Settings**.
2. Under **Local Models**, select **Explore**.
3. Search for a model or choose one of the listed models.
4. Open the model details.

Use the format filters and device-fit information to narrow the results.

## Choose a format and variant

A model may have several formats and size variants. Choose one supported by your computer.

Use the fit indicator as a guide. If a model is too large, choose a smaller variant. Larger variants usually need more memory and take longer to download and load.

## Download the model

1. Choose the download destination if more than one device is available.
2. Select the format and variant.
3. Start the download.
4. Follow progress in the downloads view.

You can pause, resume, cancel, or retry a download from the downloads view.

## Use the downloaded model

Open **Settings** → **Local Models** → **Library** to see indexed models on the device.

Then open a Bionic session and select the model labeled **Local**. Bionic loads it automatically when the session needs it.

If you downloaded the model to an LM Link device, it appears as **Remote** when that device is online and has **Share local models** enabled.

See [Choose a Cloud, Local, or Remote Model](/docs/bionic/models).
